# Tab Zoo Chrome extension prototype

이 폴더는 별도 빌드 없이 Chromium 계열 브라우저에서 직접 불러올 수 있는 Manifest V3 확장 프로그램입니다.

## 설치

1. Chrome 또는 Edge에서 확장 프로그램 관리 화면을 엽니다.
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
2. 우측 상단의 `개발자 모드`를 켭니다.
3. `압축해제된 확장 프로그램을 로드`를 누릅니다.
4. 이 `extension` 폴더를 선택합니다.
5. 툴바의 Tab Zoo 아이콘을 누르면 320×300 팝업이 열립니다.

## 현재 동작

- 활성 탭 체류시간과 최근 10분간 방문 횟수를 브라우저 로컬 저장소에 기록합니다.
- 입력이 5분간 없거나 화면이 잠기거나 브라우저 창이 포커스를 잃으면 현재 체류를 종료합니다.
- 1분 간격 하트비트와 2분 세션 만료 기준으로 브라우저 종료·기기 절전 중의 시간은 체류에 포함하지 않습니다.
- 브라우저 창이 선택된 상태에서 활성 탭이 소리를 재생 중이면 입력이 없어도 체류를 이어갑니다.
- 유휴 상태에서 같은 탭으로 돌아오면 새 체류 구간을 시작하지만 왕복 횟수는 늘리지 않습니다.
- 1분까지 알, 5분까지 유년체, 60분부터 거대종, 120분에 최대 크기가 됩니다.
- 10분 방치부터 졸리고 35분부터 잠듭니다.
- 연속 체류는 90분까지 가로폭을 넓히고, 잦은 왕복은 전체 실루엣을 좌우로 압축합니다.
- 파비콘의 대표색을 추출해 생물의 주색으로 사용합니다.
- 초원·시베리아·사막 맵을 선택할 수 있으며 선택은 브라우저에 저장됩니다.
- 작은 `알 숨기기` 버튼으로 부화 전 생물만 맵에서 감출 수 있으며 선택은 브라우저에 저장됩니다.
- 초기화 버튼은 모든 동물과 사이트별 동물 배정, 성장·체류·왕복 기록을 지웁니다. 이후 초기화 시각 뒤 실제 전면 화면으로 열린 적 있는 탭만 7종 중 무작위 종의 새 알로 표시됩니다.
- 동물 배정은 백그라운드 상태에서만 생성하며, 초기화 세대가 바뀌면 이전 팝업이 남긴 배정값은 다시 사용하지 않습니다.
- 어떤 사이트를 연 탭을 모두 닫으면(창을 닫아 함께 닫힌 경우 포함) 그 사이트의 동물과 기록이 초기화됩니다. 다시 열면 무작위 종의 새 알로 시작합니다. 같은 사이트가 다른 탭에 남아 있으면 유지됩니다.
- 브라우저를 완전히 종료했다가 다시 실행하면 모든 동물과 기록이 초기화됩니다(이전 탭 복원 포함).
- 생물을 클릭하면 원래 탭과 창으로 이동합니다.

모든 기록은 `chrome.storage.local`에만 저장되며 서버로 전송되지 않습니다.
